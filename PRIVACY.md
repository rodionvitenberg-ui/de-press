# PRIVACY.md — что мы храним и что не храним

de-press.co — некоммерческая платформа тихой поддержки. Анонимность здесь не
заявление, а устройство системы: её можно проверить по коду. Этот документ —
фактическая инвентаризация данных бэкенда (ссылки на код даны).

## Принципы

1. **Anon-first.** Регистрация не нужна ни для одной функции. Письмо и Telegram
   — опциональные каналы нотификации, а не вход по умолчанию
   (`backend/apps/identity/models.py`: `Account` — «Optional registered identity»).
2. **Минимизация данных.** Нет real-name, телефона, даты рождения, геолокации,
   аватаров, соцграфа. Псевдоним — свободная строка, вводится опционально.
3. **Никакого трекинга.** В коде приложения нет аналитики, пикселей, ads,
   fingerprinting, метрик вовлечённости. Публичные счётчики лайков отсутствуют
   по продукту (тихая эмпатия вместо виральности).
4. **ZK-паттерны — только на устройстве.** Клиентские поведенческие паттерны
   (помощь себе) живут в IndexedDB браузера и не отправляются на сервер.

## Что мы храним (и почему)

| Данные | Где | Зачем | Связь с личностью |
|---|---|---|---|
| Псевдоним, флаги дежурства хелпера, org | `Account` | работа Help-трекинга | опциональная учётка (email+пароль) |
| Email | `Account.email` | только если пользователь сам завёл учётку | опционально |
| Telegram id/username | `Account.telegram_id` | только вход через TG Mini App (ADR-0013) | опционально |
| Анонимная сессия: UUID, псевдоним | `AnonymousSession` | identity по cookie без регистрации | псевдонимна |
| Контактный email | `AnonymousSession.contact_email` | magic-link для нотификаций, опционально | опционально |
| Монологи, диалоги, сообщения | `Story`, `Dialogue`, `Message` | суть продукта | автор = UUID сессии/учётки, не имя |
| Голосовые, «кружочки» | файлы `media/` | диалоги по согласию автора | удаляются: см. retention |
| Уведомления | `Notification` | приватные события получателя | payload = только id-ссылки |
| Дайджесты | `EmailDigest` | opt-in email-нотификация | адрес нужен только для отправки |
| Репорты, блокировки | `Report`, `Block` | модерация по заявлению | псевдонимны |
| Публичный Solana-адрес чаевых | `Account.tip_wallet_address` | opt-in «поблагодарить хелпера» (ADR-0020) | публикует сам хелпер |
| Дежурные интервалы | `DutySegment` | прозрачный отчёт фонда (ADR-0020) | ссылка на учётку, в отчёте — псевдоним |
| Профиль терапевта: псевдоним, подход, языки, тариф, публичный Solana-адрес | `TherapistProfile` | каталог терапии (ADR-0022) | публикует сам терапевт, доступ по инвайту админа |
| Сессия терапии: статус, цена, псевдоним клиента, ссылки на диалог | `TherapySession` | статусы оплаты и канал сессии | платёж — прямой перевод кошелёк → кошелёк; платформа хранит только статус и сумму тарифа |

## Что мы НЕ храним

- **IP-адреса.** Код приложения нигде не пишет IP. Единственное использование —
  rate-limit каталога переводов для безсессионных запросов: в Redis кладётся
  только SHA-256-хэш, солёный `SECRET_KEY`, с TTL 1 час
  (`backend/api/v1/i18n.py`, `_rate_key`). Даже сырой IP в кэше не возникает.
- **User-Agent.** Не читается и не пишется.
- **Access-логи с IP.** Nginx на проде использует privacy-формат без IP и UA
  (`deploy/nginx-de-press.conf`, `log_format privacy`).
- **Аналитика поведения.** Нет Google Analytics / Яндекс.Метрики / Sentry-профилей.
- **Паттерны самоподдержки.** ZK-паттерны не покидают устройство.
- **Публичные метрики.** Лайки/просмотры не существуют в модели данных.
- **Ключи и платежи.** Платформа не хранит приватные ключи, не проводит
  транзакции и не держит RPC-нод: деньги идут только кошелёк → кошелёк,
  казна — публичный Squads-мультисиг (ADR-0020). Оплата терапии — прямой
  перевод клиент → терапевт; подтверждает приход сам терапевт, платформа
  не видит транзакций и не арбитр (ADR-0022).

## Retention (очистка)

- Голосовые сообщения: по умолчанию `delete_on_close` — удаляются при закрытии
  диалога (`VoiceRetention`); «сохранить» — только явный выбор автора.
- «Кружочки» (видео): удаление при закрытии диалога.
- Сессии: anon-сессия живёт в cookie пользователя, сервер ничего не знает о
  человеке за ней, кроме UUID и опциональных полей из таблицы выше.

## Верифицируемость

Всё описанное — свойства кода, а не обещания: модели — `backend/apps/*/models.py`,
middleware — `backend/apps/identity/middleware.py` (только cookie, без логов),
rate-limit — `backend/api/v1/i18n.py`, nginx — `deploy/nginx-de-press.conf`,
фонд — `backend/apps/fund/` (ADR-0020), терапия — `backend/apps/therapy/`
(ADR-0022).
Платформа self-hostable: любой может поднять свой экземпляр по
`deploy/DEPLOY.md` и проверить таблицы БД сам.
