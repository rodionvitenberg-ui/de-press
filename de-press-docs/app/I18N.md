# UI languages

Chrome only. Chat/feed bodies are not translated here.

- **Handwritten:** `ru`, `en` in `apps/browser/src/core/i18n/messages/`.
- **Everything else:** flatten the English catalog → `POST /api/v1/i18n/ui-catalog` → IndexedDB (`depress_i18n`) keyed by language + source hash.
- Picker: UserMenu → language list (`Intl.DisplayNames`). RTL codes set `html[dir=rtl]`.
- Translator down / offline stub → stay on the last working pack (usually `en`/`ru`).
- Do not use a Google Translate page widget.

New UI copy is added only to `ru.ts` / `en.ts`.
