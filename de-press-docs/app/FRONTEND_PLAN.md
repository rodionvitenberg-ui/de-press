# Frontend rework plan — de-press.co

Цель: сделать интерфейс **предельно понятным и тёплым, как Telegram / WhatsApp**, но в собственной расцветке de-press (тёмная «тихая гавань» с мятным акцентом `hope`). Полное удобство, идеальное расположение кнопок как в Телеге, хорошо и на десктопе и (структурно) на мобилке — **мобильной полировкой занимается другой кодер**, но мы закладываем правильную адаптивную структуру.

> **Платформы:** UI Core один; hosts — browser · Telegram Mini App · own desktop · own mobile. Mini App — этап, не единственный mobile. См. [`PLATFORMS.md`](./PLATFORMS.md).

План составлен по правилам шести доменных скиллов (`better-interface`, `better-accessibility`, `better-layout`, `better-writing`, `better-typography`, `better-colors`, `better-ui`) на основе аудита текущего кода.

## 2. Дизайн-токены (foundation)

### 2.1 Новые токены в `globals.css`
```css
:root {
  /* Surfaces */
  --bg-chat: #0b0d11;          /* фон чата, чуть темнее main */
  --bg-bubble-me: #1e5346;     /* my bubble — тёмно-мятный фон */
  --bg-bubble-them: #1e232c;   /* их bubble — нейтральный */
  --bg-sidebar: #12151b;       /* сайдбар/навигация */
  --bg-input: #1a1f27;         /* поле ввода сообщения */
  --bg-hover: rgba(255,255,255,0.05);
  --bg-active: rgba(126,184,162,0.18);

  /* Text on bubbles */
  --text-bubble: #eef2f6;
  --text-bubble-muted: rgba(238,242,246,0.62);

  /* Radius — концентрические */
  --radius-bubble-me: 1.15rem 1.15rem 0.4rem 1.15rem;   /* хвост справа */
  --radius-bubble-them: 1.15rem 1.15rem 1.15rem 0.4rem; /* хвост слева */

  /* Layout */
  --sidebar-width-desktop: 15rem;
  --composer-height: 3.75rem;
  --max-width-chat: 46rem;

  /* Shadows (elevation, не border) */
  --shadow-elev-1: 0 1px 2px rgba(0,0,0,.24);
  --shadow-elev-2: 0 8px 24px rgba(0,0,0,.30);
}
```

### 2.2 Контраст и цвет
- Проверить пары `--text-bubble` на `--bg-bubble-me/them` и `--text-muted` на surface через APCA (`\|Lc\| >= 60` для не-body). Мятный на тёмном — контрастный, но проверить вычислением.
- **Один цвет — одно значение**: `accent-hope` = действие/подсветка активности, `accent-panic` = кризис/деструктив. Не красить декоративно.
- Гамма: сохраняем HEX (проектный формат), не переводим в oklch без миграции всего.

### 2.3 Font
- Оставить `system-ui` (уже хорош), добавить `font-variant-numeric: tabular-nums` для счётчиков (unread badge, pulse).
- `text-wrap: balance` на заголовках секций, `pretty` на описаниях.
- Продолжить `-webkit-font-smoothing: antialiased` (уже есть).

## 3. Каркас и навигация (Telegram-like)

### 3.1 Десктоп: сайдбар слева (аналог Telegram Web)
- Новый компонент `Sidebar` (вместо перегруженного хедера):
  - Верх: бренд `de-press` + `NotificationBell`.
  - Пункты (иконка + подпись): **Лента** `/feed`, **Чаты** `/me` (диалоги — с badge unread), **Helper** `/helper` (только Helpers), **Паттерны** `/patterns`, **Помощь** `/help`, **Гайды** `/guides`, **Безопасность** `/safety`, **О проекте** `/about`.
  - Низ: вход/аккаунт + переключатель языка + **Anti-Panic** (отдельная красная кнопка).
  - Активная страница: `aria-current="page"` + подсветка `--bg-active` + левый индикатор-полоска.
- `Header` сократить до: (на мобиле скрыть) бренд + bell + panic; вся навигация переезжает в сайдбар.
- **Адаптив (для мобильного кодера)**: сайдбар на `< 900px` превращается в **нижний таб-бар** с 4–5 пунктами (Лента, Чаты, Моё??, Паттерны, Ещё) — закладываем структуру компонента `BottomNav`, стили позже.

### 3.2 Shell
- `Shell.tsx`: слева `Sidebar`, справа контент; контент — `max-width` по разделам.
- Секции-«списки» как в TG: group with space, не line-разделители (убрать `border-bottom` везде, где можно, заменить `gap`).

### 3.3 Skip-link и landmarks
- Добавить «Перейти к содержимому» первым фокус-элементом; `<main id="main">` уже есть.

## 4. Чат — сердце как в WhatsApp/Telegram

### 4.1 Композер прижат к низу
`DialogueClient` → макет:
```
[ шапка чата: ← назад | intent · status | ⋯ (hide/report) ]
[               thread (скроллируемый)                    ]
[                    composer (sticky bottom)             ]
```
- `.thread` получить `min-height` через `height: calc(100dvh - header - composer)` и `overflow-y: auto`; composer — `position: sticky; bottom: 0` внутри flex-колонки роста на всю высоту экрана (как TG web).
- **Поле ввода внизу**: `<textarea>` (1 строка, авторост до 5) + **кнопка микрофона** слева от поля + **кнопка отправки** справа (появляется при непустом тексте) — паттерн WhatsApp.
- При записи: кнопка стоп/отмена — в строке композера (заменить общий ряд кнопок).
- «Закрыть диалог» и «Скрыть собеседника» — в шапку (`⋯` меню), не в композер.

### 4.2 Пузыри (более «мессенджерные»)
- `.me` — справа, фон `--bg-bubble-me`, радиус с хвостом справа (`--radius-bubble-me`); время + (опц.) «галочка» — маленькая строка под текстом.
- `.them` — слева, `--bg-bubble-them`, хвост слева.
- `.system` — по центру, деликатно, без фона.
- Время сообщения — `HH:MM`, `tabular-nums`.
- Voice: более компактный плеер (как запись в TG), прогресс по времени.

### 4.3 Кружочки (video circles) — UI-каркас
- В композер добавить кнопку «кружочек» (видео). Пока backend не готов — кнопка скрыта/disabled с тултипом «скоро». UI-паттерн: запись в круге, как TG (удержание или tap-to-record в будущем).
- Голосовые с опцией удаления — переключатель в настройках (см. приоритеты ROADMAP), композер использует `VoiceRecorder` с опциями.

## 5. Экраны-разделы (списки как в Telegram)

### 5.1 Лента `/feed`
- Композитор «Написать тихо» — **сворачиваемый** (кнопка «Написать» как в TG композере) или компакт-строка вверху списка; публикация — та же форма, но не раздувает ленту.
- `StoryCard` — карточка-строка: тема (бейдж), монолог-превью (max 3 строки, `line-clamp`), псевдоним/время; клик → деталь.
- Фильтр тем — компактный `<select>` или чипы (chips) — чипы понятнее и красивее, как фильтры в TG.

### 5.2 `/me` (Чаты/Моё)
- Разбить на **вкладки** или группировки: «Диалоги», «Запросы», «Мои истории» — как telegram-списки с правыми шевронами.
- Dialogue row: статус (live/closed), intent, непрочитанный badge — строка с аватаром-плейсхолдером (инициал).
- NotifySettings, clouds, hearers — остаются автор-секциями, но в едином стиле карточек.

### 5.3 `/helper`
- Очередь облачков — list rows с кнопками Approve/Reject (подтверждать действие: `verb-first` labels из i18n).

### 5.4 Anti-panic
- Оставить минимализм. Не менять поведение. Только проверить фокус и крупные hit areas.

### 5.5 literacy (`/guides`, `/help`, `/safety`, `/about`, `/patterns`, `/companion`, `/helper`, `/inbox`)
- Единый шаблон «экран-страница»: заголовок, intro, контент; широкие поля, measure ~65ch.

## 6. Компоненты (better-ui)

### 6.1 Button
- `active: scale(0.96)`; `transition-property: transform, background-color, box-shadow` (никогда `transition: all`).
- Shadow-elevation вместо бордера-для-глубины; бордер — только структура/состояние.
- Минимальный hit area 40×40 (desktop), 44×44 (touch) — расширить через `::after` там, где визуально меньше.

### 6.2 Icons
- **Единая иконографика**: один набор, `stroke=1.5–2px` под текст, `currentColor`; fill — только активное состояние.
- Иконки: лента, чаты, helper, паттерны, помощь, безопасность, гайды, о проекте, настройки, микрофон, камера (кружочек), галочка, ⋯, выход-panic.

### 6.3 Анимации
- Enter/exit вкладок/модалок: `opacity + translateY(4px)` за 150–200ms, `ease-out`; stagger секций ~100ms только для редких входов.
- Точки «печатает…» уже есть — оставить.
- `prefers-reduced-motion` уже глобально — сохранить.

### 6.4 Радиусы
- Концентрические: пузырь внутри чата → вложенные элементы; сайдбар-активный-пункт (radius-lg) с внутренним индикатором (radius-sm). Соблюдать `outer = inner + padding`.

## 7. Доступность (better-accessibility)

- **Focus**: уже есть `:focus-visible` + `--focus-ring`; проверить на всех новых сайдбар-ссылках и пузырях-действиях (translate/report — кнопки получат видимый ring).
- **Hit areas**: минимум 40×40; боковые сайдбар-ссылки сделать на всю ширину и высотой 44px.
- **Aria**:
  - Иконки-действия: `aria-label` (перевод, репорт, микрофон, закрыть меню).
  - Пузыри-кнопки `translate/report` — настоящие `<button>` (уже), но добавить `aria-label`.
  - Счётчик unread — `aria-live="polite"` не спамить; стабильный `role="status"`.
  - Меню шапки чата (`⋯`) — Escape закрывает, roving tabindex не нужен (простое меню).
- **Zoom 200% / 320px**: чек списком; текстовые контейнеры `min-height` вместо фикс-высот, `rem` в токенах.
- **Skip link** — первым фокус-элементом.

## 8. Тексты (better-writing)

- Все кнопки — verb-first: «Написать», «Отправить запрос», «Approve», «Reject», «Закрыть диалог», «Скрыть собеседника».
- Пустые состояния — с ориентацией и действием (в ленте/чатах уже есть; довести единый стиль).
- Один регистр: sentence case для кнопок и заголовков.
- Уведомления/дайджест — «у тебя», не «у пользователя».
- Все новые строки — в `types.ts` + `ru/en`.

## 10. Принципы переработки (не ломать)

1. **НЕ Tailwind** — CSS Modules + токены (правило проекта).
2. Сохранить смыслы: лента остаётся «монологами-облачками», чат — «посидеть рядом», без геймификации и публичных счётчиков.
3. Anti-Panic — неизменный минимализм, важнее ленты.
4. Мобильную полировку делает другой кодер — мы даём структуру (`Sidebar` → `BottomNav`), но визуал мобилки — его зона.
5. Всё новое — сразу в i18n ru/en.
6. `prefers-reduced-motion` и фокус-ринги — обязательно.
